每张图一个指标，最新版本用青色，其余灰色。鼠标停在条上看具体数值。准确度是评审分除以 2；幻觉指与原文或反例矛盾的回答占比；无依据说法是材料里找不到但也不矛盾的具体说法。

按题型的准确度

每个题型的题数不多（3–12 道），单格的差别要看趋势，不能逐格下结论。

前提核对（错误前提、问事实、问细节，29 题 × 3 次）

C2 在 C 的基础上，把问事实和问原因的提纲第一块改成“前提：问题里认定的事对不对”，前提不对时回答第一句先纠正。只重跑了这三类题，所以单独列一张表。

讲述完整度盲评（大体经过、跨章节题）

arc:chat 在不知道版本的情况下只看表达方式打分：有没有点题、交代起因、按先后讲、讲出结果、开头结尾有没有推托或客套，以及像不像人在讲自己的经历（1–5）。

30 道未参与调整的新题

代表题在各版本下的回答

原型阶段的单次运行，用来看说话方式的变化；每一行是一次真实输出的节选。成本是这一轮的模型调用次数和接口返回的输入/输出 token。

指针 CoT（C）比 v1.2.28 修正版（B1）多出的幻觉

  • 展开时补进了记忆里没有的细节：涅瓦湖那题 3 次都把原文的“挥剑”说成“挥动法杖”（模型自带的印象）；另有一次把“克制住想拥抱的冲动”说成“克制不住”。
